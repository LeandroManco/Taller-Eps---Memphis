Sobre el Proyecto:

El objetivo del proyecto es migrar la landing page de VITA+ Centro Médico (escrita en un solo archivo HTML con Tailwind vía CDN y estética Memphis) hacia una aplicación web modular en React + Vite, para que un paciente pueda consultar los servicios de la clínica y agendar una cita dentro de una arquitectura moderna, mantenible y bien versionada.

Para qué le sirve al usuario final
La página sirve como vitrina y punto de contacto de VITA+ Centro Médico para:
Conocer la atención 24/7 y las 6 áreas médicas (Cardiología, Pediatría, Odontología, Laboratorio, Urgencias y Oftalmología).
Revisar el equipo médico, los planes mensuales (Esencial, Familiar y Preventivo+) y la tecnología clínica (resonancia, historial cloud, laboratorio rápido y farmacia).
Elegir un horario, llenar sus datos para solicitar una cita o ubicar la dirección y el teléfono de contacto.
